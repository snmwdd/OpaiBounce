# Security Policy

## Supported Versions

OpaiBounce is still in early development. Security fixes are generally provided for the latest versions only.

| Component | Version | Supported |
| --- | --- | --- |
| OpaiBounce Theme | 0.1.x | ✅ |
| OpaiBounce Script | 1.5.x | ✅ |
| Older versions | All | ❌ |

Support may change as new versions are released.

## Reporting a Vulnerability

If you discover a security vulnerability in OpaiBounce, please report it responsibly.

**Please do not publish sensitive vulnerabilities, working exploits, or private information in public issues.**

You can report security issues through GitHub's private vulnerability reporting feature, if it is enabled for this repository.

For general bugs that do not involve security risks, feel free to open a regular GitHub issue.

When reporting a vulnerability, please include:

- A description of the issue
- The affected component and version
- Steps to reproduce the issue
- The potential security impact
- Any relevant logs or screenshots (without exposing sensitive information)

I'll review security reports when possible, but I can't guarantee a specific response or fix time.

## Disclosure

Please allow reasonable time to investigate and fix confirmed vulnerabilities before making technical details public.

Not every report will necessarily result in a security update.

Thanks for helping keep OpaiBounce safe.
